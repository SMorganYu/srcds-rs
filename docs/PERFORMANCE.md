# Performance

Сравнительных измерений с SRCDS **нет**: srcds-rs пока не выполняет симуляцию, поэтому любое
сравнение было бы нечестным.

## Что собирается

`Metrics` (srcds-core): пакеты/байты in/out, malformed, rate_limited, по типам запросов,
количество тиков, overruns, длительность тика p50/p95/p99/max (кольцо 4096 образцов).
Логируется каждые `--metrics-interval` секунд.

## Измерения

| Дата | Сценарий | Результат |
|---|---|---|
| 2026-11-14 | release, пустой сервер, 5 с | 334 тика (ожид. 333), p99 тика < 1 мкс |

## Методология (на будущее)

* Одинаковые сценарии для SRCDS и srcds-rs (карта, игроки/боты, сущности, длительность).
* Распределения задержек (p50/p95/p99), а не средние.
* Отдельно: время обработки пакета, построение снапшота, Lua-время, аллокации.
