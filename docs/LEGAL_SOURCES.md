# Legal sources policy

| Источник | Статус | Как используется |
|---|---|---|
| Valve Developer Wiki «Server queries» | публичная документация | основа форматов A2S/split |
| Чёрный ящик: собственная установка GMod DS | лицензия пользователя на игру | захват ответов на loopback/LAN, без распространения игровых файлов; в репозитории — только сетевые ответы собственного тестового сервера (`tests/fixtures`) |
| Захват handshake с оригинальным клиентом | собственный трафик пользователя | захваты лежат **вне репозитория**: содержат Steam-тикет и имя пользователя. В репозиторий попадают только синтетические тест-векторы |
| Импорт-таблицы и строки бинарников | интероперабельность | только факты (имена модулей/сообщений), код не копируется |
| Source SDK 2013 (ValveSoftware) | SOURCE 1 SDK LICENSE | читались публичные заголовки (`proto_version.h`: PROTOCOL_VERSION 24) и формат LZSS (`tier1/lzss`); код не копировался, LZSS реализован независимо |
| Source-Authors/Obsoletium (по ссылке пользователя) | форк движка; происхождение кода движка не подтверждено как открытое | клонирован **вне репозитория** (`D:\!gmod\refs`), используется **только как справочник** по номерам сообщений и порядку полей; код не копируется и не транслируется, реализация srcds-rs своя, проверена захватами |
| nillerusr/source-engine | производное от утёкших исходников | **не используется** |
| `csgo_partner/src` | неофициальная публикация, статус не подтверждён | **не используется** |
| Facepunch/garrysmod (Lua) | публичный репозиторий | планируется для M6 (проверить лицензию перед использованием) |
| Steamworks SDK (`steam_api64.dll`) | Steamworks SDK Access Agreement | планируется для `srcds-steam` (FFI к официальной DLL, без распространения) |

Правила: никакой механической трансляции C++ → Rust; никакого декомпилированного кода;
никаких игровых ассетов в репозитории; секреты (токены, публичный IP) не коммитятся.

Зависимости crates (все MIT/Apache-2.0): `thiserror`, `tracing`, `tracing-subscriber`,
`clap`, `ctrlc`, `rand`, `md-5`.
