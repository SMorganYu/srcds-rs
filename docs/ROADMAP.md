# Roadmap

| Milestone | Критерий | Статус |
|---|---|---|
| M0 Bootstrap | Rust-процесс, UDP, корректный shutdown | **Достигнут** (тесты) |
| M1 Query compatibility | Корректные A2S_INFO/PLAYER/RULES | **Достигнут на уровне протокола** (golden-тесты с эталоном); проверка браузером серверов клиента — не выполнена |
| M2 Network handshake | Оригинальный клиент проходит стадии соединения | **Достигнут** (живой тест: `Connected to`, ServerInfo принят, чистый disconnect; e2e-тест) |
| M3 World loading | Клиент загружает gm_construct | **Достигнут** (живой тест: оригинальный клиент доходит до SignonState(FULL), `Map: gm_construct`, без краша) |
| M4 Player simulation | Спавн и движение | **Достигнут**: спавн, ходьба/присед/прыжок/noclip по BSP и displacement, сверено с предсказанием живого клиента |
| M5 Multiplayer | Два клиента видят друг друга | — |
| M6 GMod runtime | GLua + Sandbox | **Частично**: серверный GLua грузит sandbox без ошибок; пропы/оружие/физган/net/чат реализованы и покрыты e2e-тестом; живая проверка в клиенте — в процессе |
| M7 Extended | Аддоны, режимы | — |
| M8 Optimization | Честные сравнительные нагрузочные тесты | — |

## Ближайшие задачи (M6)

1. Живая проверка в оригинальном клиенте: Q-меню → проп, физган (захват/бросок/заморозка),
   тулган (weld/remover), чат, смерть/респавн, меню C.
2. Констрейнты (weld, rope, axis…) в физике пропов; вращение при контактах.
3. NPC: AI/движение (сейчас статичные модели).
4. `sql` (sv.db), `file.Open`, `game.AddParticles`.
5. `m_bIsTyping` из usercmd-флага чата; `CGMODGameRulesProxy`.

## Прежние задачи (M4 → M5)

1. Подтвердить живым вводом noclip-движение без «откатов» предсказания; при
   расхождениях — сверить параметры (`sv_maxspeed`, `sv_noclip*`, `sv_friction`) и
   поведение `IN_SPEED`.
2. Ходьба: сделана (brush-коллизия, гравитация, ступеньки, прыжок). Дальше: присед,
   displacement-рельеф, пропы, вода, лестницы.
3. Смысл 6 флагов хвоста usercmd GMod (редкий случай «все шесть установлены»).
4. Пинг (`m_iPing`) из RTT netchannel; `CGMODGameRulesProxy`/`CTeam` при необходимости.
5. M5: два клиента видят друг друга (сущности других игроков, `m_angEyeAngles`).
6. M6: серверный GLua-рантайм (`AddCSLuaFile` вместо правил отбора файлов).
7. `srcds-steam`: FFI к официальному `steam_api64.dll` для не-LAN режима.
